connect your Firebase project
This app stores data in your own free Firebase project so every family member's phone stays in sync. One-time setup:
  1. Go to console.firebase.google.com → Create a project
  2. Build → Firestore Database → Create database → start in test mode
  3. Build → Authentication → Sign-in method → enable Anonymous
  4. Project settings → General → scroll to "Your apps" → Add app → Web (</>) → copy the firebaseConfig object
  5. Paste that whole object below
